# Spam Mail Prediction Using Supervised Learning

This project demonstrates spam mail prediction using **Supervised Learning** in a **Classification** setting. The model utilizes **TF-IDF vectorization** for text feature extraction and **Multinomial Naive Bayes (MultinomialNB)** for classification.

## Project Description

The goal of this project is to classify emails as **spam** or **ham (non-spam)** using a machine learning model. The model is trained using a labeled dataset of emails, where each email is represented as text data. The following key steps are involved:

1. **Text Preprocessing**: Cleaning and preparing the text data for feature extraction.
2. **Vectorization**: Converting text into numerical features using.
3. **Model Training**: Training a **Multinomial Naive Bayes** & **LogisticRegression model for classification.
4. **Evaluation**: Evaluating the model's performance using various metrics like accuracy, precision, recall, and F1-score.

## Dataset

The dataset used in this project is a collection of emails labeled as **spam** or **ham (non-spam)**. Each email contains text data that will be processed and vectorized to train the model.
